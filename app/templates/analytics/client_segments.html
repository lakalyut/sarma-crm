Детали расчёта
  • ABC учитывает положительный объём отгрузок. При равном весе клиенты идут по названию. Клиент, пересекающий границу, остаётся в группе, которая набирала эту долю.
    • {% if mode == 'presence' %}
  • Несколько отгрузок в одном месяце считаются как один месяц с закупкой. Клиенты без закупок за период показаны отдельно.
    • {% else %}
  • CV — стандартное отклонение месячного веса, делённое на среднее и умноженное на 100. Сезонность и тренд отдельно не корректируются.
    • {% endif %}
  • В выбранном месяце без закупок клиента учитывается ноль. Для XYZ нужны как минимум два месяца и достаточная история клиента.
  • Клиенты объединяются по названию внутри города с учётом типа точки. Месяцы берутся из загруженных продаж города. Сопоставление товара со справочником, поиск и выбор сегмента сохраняют исходную базу расчёта.
