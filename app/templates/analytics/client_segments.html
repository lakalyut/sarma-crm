Как рассчитываются классы

ABC показывает вклад клиента в положительный объём отгрузок выбранного города и типа точки. При выборе типа классы и доли пересчитываются внутри этого типа. Клиенты упорядочены по объёму, при равенстве — по названию. A — до достижения 80% накопленной доли, B — до 95%, C — остальные. Клиент, пересекающий границу, остаётся в начавшемся классе.

{% if mode == 'presence' %}

XYZ показывает долю месяцев с положительной отгрузкой. X — от 80% месяцев включительно, Y — от 50% до 80%, Z — менее 50%. За 6 месяцев X означает 5–6 месяцев с закупками, Y — 3–4, Z — 1–2. За 12 месяцев X — 10–12, Y — 6–9, Z — 1–5. Клиенты без закупок за период показаны отдельно. Несколько отгрузок внутри одного месяца учитываются как один месяц с закупкой.

{% else %}

XYZ показывает колебания месячного объёма. CV — стандартное отклонение за все месяцы окна, делённое на среднее. X ≤ 25%, Y ≤ 50%, Z > 50%.

{% endif %}

В полном отчёте отсутствие закупок клиента считается нулём. При короткой истории или пропусках отчётов XYZ не присваивается.

Клиенты объединяются по названию внутри города с учётом фильтра типа точки. Полнота месяцев проверяется по данным всего города. Сопоставление товара со справочником не меняет вес отгрузки. Поиск и выбор сегмента сохраняют исходную базу расчёта. Сезонность и тренд отдельно не корректируются.

{% else %}

Выберите город для расчёта сегментов клиентов.
