Как считаем ABC и XYZ

ABC показывает вклад клиента в положительный объём отгрузок выбранного города и типа точки. При выборе типа классы и доли пересчитываются внутри этого типа. Клиенты упорядочены по объёму, при равенстве — по названию. A — до достижения {{ report.settings.client_abc_a }}% накопленной доли, B — до {{ report.settings.client_abc_b }}%, C — остальные. Клиент, пересекающий границу, остаётся в начавшемся классе.

{% if mode == 'presence' %}

XYZ показывает долю месяцев с положительной отгрузкой. X — от {{ report.settings.xyz_presence_x }}% месяцев включительно, Y — от {{ report.settings.xyz_presence_y }}% до менее {{ report.settings.xyz_presence_x }}%, Z — менее {{ report.settings.xyz_presence_y }}%. Клиенты без закупок за период показаны отдельно. Несколько отгрузок внутри одного месяца учитываются как один месяц с закупкой.

{% else %}

XYZ показывает колебания месячного объёма. CV — стандартное отклонение за все месяцы окна, делённое на среднее. X ≤ {{ report.settings.xyz_cv_x }}%, Y ≤ {{ report.settings.xyz_cv_y }}%, Z > {{ report.settings.xyz_cv_y }}%.

{% endif %}

В выбранном месяце без закупок клиента учитывается ноль. XYZ рассчитывается при выборе как минимум двух месяцев и достаточной истории клиента.

Клиенты объединяются по названию внутри города с учётом фильтра типа точки. Список месяцев формируется по загруженным продажам города. Сопоставление товара со справочником не меняет вес отгрузки. Поиск и выбор сегмента сохраняют исходную базу расчёта. Сезонность и тренд отдельно не корректируются.
